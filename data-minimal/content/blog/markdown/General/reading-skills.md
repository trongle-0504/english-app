## I. PHÂN TÍCH CÂU 2 VẾ (MỐI QUAN HỆ LOGIC)
Khi đọc các câu dài, việc đầu tiên là nhận diện các liên từ nối 2 vế câu để hiểu mối quan hệ logic giữa chúng.

### 1. Nguyên nhân - Kết quả (Cause - Effect)
Đưa ra nguyên nhân và kết quả, khi đọc cần chú ý chiều nhân quả (1) → (2). Lời khuyên khi ghi chú là không được thay đổi thứ tự nhân quả.

| [SV] - [SV] | [N], [SV] | [V-ING], [SV] | PURPOSE (Mục đích) |
| :--- | :--- | :--- | :--- |
| Because SV, SV | Thanks to N, SV | By V-ing, SV | In order to V, SV |
| As SV, SV | Due to N, SV | SV, thereby V-ing | To V, SV |
| Since SV, SV | Owing to N, SV | | So as to V, SV |
| If SV, SV | Because of N, SV | | SV, so that SV |
| S_V, so S_V | As a result of N, SV | | |
| S_V, for S_V | | | |

*   **Ví dụ:** **Because** her parents are very strict, she sometimes feels stressed. 
    *(Main idea: strict parents → stressed)*
*   **Ví dụ:** **By** doing exercise regularly, they can improve their health. 
    *(Main idea: do exercise regularly → better health)*
*   **Ví dụ:** **In order to** pass the exam, she studied hard every day. 
    *(Main idea: study hard → pass exam)*

### 2. Tương phản (Contrast)
Thể hiện hai vế có ý nghĩa trái ngược nhau (1) # (2).

| [SV] - [SV] | [N], [SV] | EVEN ... |
| :--- | :--- | :--- |
| Although SV, SV | Despite N, SV | Even if SV, SV |
| Though / Even though SV, SV | In spite of N, SV | Even when SV, SV |
| While / Whilst SV, SV | Notwithstanding N / that SV, SV | |
| Whereas SV, SV | Regardless of N, SV | |
| SV, but SV | | |
| SV, yet SV | | |

*   **Ví dụ:** The car is old, **yet** it still runs well. 
    *(Main idea: old car # run well)*
*   **Ví dụ:** **Despite** the weather, many people still joined the concert. 
    *(Main idea: bad weather # many joined the concert)*
*   **Ví dụ:** **Regardless of** the difficulty, they completed the project on time. 
    *(Main idea: difficulty # completed on time)*

### 3. Thời gian (Time)
Giúp người đọc xác định trật tự thời gian: "Cái gì trước, cái gì sau".

| BEFORE | DURING | AFTER |
| :--- | :--- | :--- |
| Before SV / N / V-ing, SV | During N, SV | After SV / N / V-ing, SV |
| Prior to N, SV | While SV / V-ing, SV | Following N, SV |
| | | Since N / SV, SV |
| | | As soon as SV, SV |
| | | When SV, SV |
| | | Once SV, SV |
| | | As SV, SV |

*   **Ví dụ:** **When** they arrived at the island, they discovered a new species of turtle. 
    *(Main idea: Ra đảo → Phát hiện giống rùa mới)*
*   **Ví dụ:** **Prior to** the meeting, all documents had been prepared carefully. 
    *(Main idea: chuẩn bị tài liệu trước cuộc họp)*

### 4. Tương đồng (Similarity)
Dùng để nối các ý tương đương. Khi đọc cấu trúc này, nếu hiểu 1 vế thì có thể suy ra vế kia. Đặc biệt từ "nor" mang nghĩa phủ định cả 2 vế.

| [SV] - [SV] | [SV] - [VS] |
| :--- | :--- |
| S_V, and S_V | S_V, nor V_S |
| S_V, or S_V | |

*   **Ví dụ:** I like shopping, **and** I like hanging out with friends *(Main idea: my hobbies)*.
*   **Ví dụ:** She is not at home, **nor** is she at school *(Main idea: she is not at home and school)*.

### 5. Điều kiện (Condition)
Thể hiện điều kiện để một sự việc xảy ra: (1) → (2) hoặc vế loại trừ / phủ định.

| [SV] - [SV] | [N], [SV] | Phủ định / Loại trừ |
| :--- | :--- | :--- |
| Providing (that) SV, SV | But for N, SV | Unless SV, SV |
| Provided (that) SV, SV | Without N, SV | SV; otherwise, SV |
| If SV, SV | With N, SV | SV; or else SV |
| So / As long as SV, SV | | |
| Under / On the condition that SV, SV | | |

*   **Ví dụ:** **Provided that** you finish your work on time, you can go home early. 
    *(Main idea: finish work → go home early)*
*   **Ví dụ:** **Without** your help, we could not have completed the project. 
    *(Main idea: no help → project failed)*

### 6. So sánh (Comparison)
Dùng để so sánh sự giống nhau hoặc khác nhau giữa các đối tượng.

| SIMILARITY (... N, SV) | DIFFERENCE (... N, SV) |
| :--- | :--- |
| Like N, SV | Unlike N, SV |
| Similar to N, SV | As opposed to N, SV |
| Same as N, SV | Different from N, SV |
| | Contrary to N, SV |
| | In contrast to / with N, SV |

*   **Ví dụ:** **Unlike** his brother, John is very talkative. 
    *(Main idea: John # his brother)*
*   **Ví dụ:** **In contrast to** the previous report, the new data shows a significant increase. 
    *(Main idea: new data # old report)*

### B. Cấu trúc câu đơn giản (Simple structures)

Cấu trúc nền tảng của một câu đơn giản được hình thành từ sự kết hợp giữa **Chủ ngữ (Subject)** và **Động từ (Verb)**:

| SUBJECT (Chủ ngữ) | VERB (Động từ) |
| :--- | :--- |
| • **Pronoun** *(Đại từ)* <br><br> • **Noun \| Noun Phrase-Clause** *(Danh từ / Cụm danh từ / Mệnh đề danh từ)* <br><br> • **Ving** *(Danh động từ)* <br><br> • **There** <br><br> • **It** | • **be** <br> &nbsp;&nbsp;&nbsp;&nbsp;+ adj + pattern <br> &nbsp;&nbsp;&nbsp;&nbsp;+ noun + pattern <br><br> • **common verbs (verb pattern)** |

### C. Biến tấu 1 Danh từ (Mở rộng Noun)
Từ một danh từ cốt lõi, tác giả có thể thêm thắt nhiều thành phần để tạo thành cụm từ, mệnh đề.

#### 1. Mở rộng thành Cụm danh từ (Noun phrase)

| Noun phrase = | Determiners | (Adv) Adj \| Noun | **NOUN** | |
| :--- | :--- | :--- | :--- | :--- |
| | **Số lượng:** many, a lot of, a number of ... | | | pattern |
| | **Referring:** his, her, this, those, the, noun's... | | | example |
| | | | | Cụm giới từ |


Cấu trúc thường gặp: `Determiners + (Adv) Adj / Noun + NOUN CHÍNH + Cụm giới từ / Mệnh đề`. 


*   *Small Practice:* A lot of her newly - grown **plants** in the garden / Technological **developments** such as household appliances or robots.

#### 2. Biến một câu thành danh từ (Noun Clause)

Thay vì chỉ dùng một từ đơn (như *Money, Success*), ta dùng **cả một mệnh đề (có Chủ ngữ - Vị ngữ)** để đóng vai trò như một "danh từ khổng lồ" trong câu.

* **Cách nhận diện:** Cụm này thường bắt đầu bằng các từ hỏi (What, Who, Why...) hoặc "That", "Whether".
* **Các cấu trúc phổ biến:**
    * **What / WH- + S + V:** Những gì / Điều mà... (Ví dụ: *What she said* - Những gì cô ấy nói).
    * **That + S + V:** Việc mà... / Sự thật là... (Ví dụ: *That he failed* - Việc anh ấy thất bại).
    * **Whether + S + V (or not):** Liệu rằng... có hay không.

* **Phân tích ví dụ:**
    > **[What doesn't kill you]** makes you stronger.
    > 
    > * **Mệnh đề danh từ (Chủ ngữ):** *What doesn't kill you* (Những gì không quật ngã được bạn).
    > * **Hành động chính:** *makes* (làm cho).
    > * **Ý chính:** Những khó khăn giúp bạn mạnh mẽ hơn.

> [!TIP]
> **Mẹo kiểm tra:** Hãy thử thay cả cụm bắt đầu bằng *What/That* bằng từ **"Something"** hoặc **"It"**. Nếu câu vẫn đúng cấu trúc thì đó là Mệnh đề danh từ.
> *Ví dụ: [Something] makes you stronger.* → Hợp lý!

#### 3. Mở rộng thành Mệnh đề quan hệ (Relative clause)
Chức năng chính là đóng vai trò như một thành phần phụ để làm rõ nghĩa cho danh từ đứng ngay trước nó. 

**Cấu trúc và cách nhận diện:**
| Cách thức | Cấu trúc | Bổ sung cho người / vật |
| :--- | :--- | :--- |
| **Sử dụng đại từ quan hệ** | Noun + **who / whom / whose / which / that + S_V** | who, whom, whose (người) / which, that (vật) |
| **Dạng rút gọn** | Noun + **V-ing** (chủ động) / Noun + **V3/ed** (bị động) | |
| **Dạng đảo** | **V-ing**, S V / **V3/ed**, S V | |

*   *Ví dụ rút gọn:* The **song written by Taylor Swift** is very famous.
*   *Ví dụ đảo:* **Given scholarships**, many poor students can now continue their education.

### D. Biến tấu cả câu
Thay vì mở rộng một danh từ, tác giả có thể lồng ghép cấu trúc câu vào một khung mới.

#### 1. Câu tường thuật (Reported speech)

##### Cách nhận diện Reported speech trong câu

* **S-V** + **Ai đó nói rằng**
* **Ai đó nói rằng** + **S-V**
* **S,** + **Ai đó nói rằng** + **, V**

| SUBJECT | REPORTING VERB + (THAT) | S - V |
| :--- | :--- | :--- |
| A study | showed | *main idea* |
| Research | found | |
| Scientists | discovered | |
| Researchers | revealed | |
| | suggested | |
| | demonstrated | |
| | confirmed | |
| | proved | |
| | unveiled | |

Nhận diện cấu trúc này thông qua cụm: **Ai đó nói rằng (say, claim, believe, think, mention, suggest, show, admit, find, according to...)**. 
*   **Cách đọc:** Nhận thấy cấu trúc này, hãy tập trung đọc ngay cụm **S-V đứng sau chữ "that"** vì đó mới là thông tin trọng tâm.
*   **Ví dụ:** Experts researching the effects of different types of food at the National University **say that** excessive consumption of junk food can increase the risk of diseases.... 
    $\rightarrow$ *Main idea:* Excessive consumption of junk food can increase the risk of diseases.

#### 2. Câu chẻ (Cleft sentence)
Dùng để nhấn mạnh một thành phần cụ thể trong câu.

##### 📌 2.1. It-cleft (dạng cơ bản – quan trọng nhất)
*   **Cấu trúc:** **It was / is + [Thành phần nhấn mạnh] + that + [Thành phần chính]**.
*   **Cách đọc:** Đọc thông tin xuất hiện sau cụm **"It was"** hoặc tìm chữ **"that"** và đọc thành phần chính sau nó.
*   **Ví dụ:** ~~It is~~ **by treating each other with consideration...** ~~that~~ **a long lasting and happy marriage can be maintained**.
##### 📌 2.2. Wh-cleft (What-cleft)

* **Cấu trúc:**    **What + S + V + is/was + [thành phần nhấn mạnh]**
* **Cách hiểu:**    = “Điều mà…”
* **Ví dụ:**
  - What I need is **a good rest**.  
  → Điều tôi cần là nghỉ ngơi
  - What makes me happy is **music**.  
  → Điều làm tôi hạnh phúc là âm nhạc
##### 📌 2.3. All-cleft
* **Cấu trúc:**    **All + S + V + is/was + [thành phần nhấn mạnh]**
* **Ví dụ:**
  - All I want is **peace**.  
  → Tất cả những gì tôi muốn là sự bình yên
##### 📌 2.4. The reason / The thing (dạng hay dùng trong IELTS)
* **Cấu trúc:**    **The reason why + S + V + is/was + ...**
* **Ví dụ:**
  - The reason why I left is **that I was tired**.  
  → Lý do tôi rời đi là vì tôi mệt
##### 🧠 Cách hiểu nhanh
👉 Câu chẻ = trả lời câu hỏi: Ai? Khi nào? Ở đâu? Cái gì?
**Ví dụ:**
- Who broke the window?  
→ It was John that broke the window
##### ⚠️ Lưu ý quan trọng
- Dùng **who** khi nhấn mạnh người  
- Dùng **that** cho vật / thời gian / địa điểm  
- Không cần lược bỏ “It is/that” trong câu chuẩn

##### 🎯 Mẹo dùng nhanh

- Muốn nhấn mạnh → dùng **It-cleft**
- Muốn diễn đạt tự nhiên hơn → dùng **What-cleft**
- Trong IELTS Writing → dùng **The reason...** để tăng điểm

### E. Các cách đảo vị trí thông tin (Information Inversion)

| STT | Phương pháp đảo | Công thức biến đổi | Ví dụ minh họa |
| :---: | :--- | :--- | :--- |
| **1** | **Sử dụng Mệnh đề quan hệ** | **Adj + N** <br>$\leftrightarrow$ **N + (which/that + to be) + Adj** | *traditional farming methods* <br>$\leftrightarrow$ *farming methods which are traditional* |
| **2** | **Sử dụng Cấu trúc ví dụ** | **N (chung chung) + such as + N (cụ thể)** <br>$\leftrightarrow$ **N (cụ thể) + and other + N (chung chung)** | *countries such as Vietnam and Laos* <br>$\leftrightarrow$ *Vietnam, Laos and other countries* |
| **3** | **Sử dụng Cấu trúc liệt kê** | **A, B and C** <br>$\leftrightarrow$ **C, A and B** *(đảo vị trí các vế)* | *air, water and noise pollution* <br>$\leftrightarrow$ *noise, water and air pollution* |
| **4** | **Sử dụng Cấu trúc 2 vế** | **Because/Although + A, B** <br>$\leftrightarrow$ **B + because/although + A** | *Because it rained, we stayed home.* <br>$\leftrightarrow$ *We stayed home because it rained.* |
| **5** | **Sử dụng Câu bị động** | **A + V + B** *(Chủ động)* <br>$\leftrightarrow$ **B + be + V3/ed + (by A)** *(Bị động)* | *Scientists discovered new species.* <br>$\leftrightarrow$ *New species were discovered by scientists.* |

## III. THỰC HÀNH: PHƯƠNG PHÁP TÌM Ý CHÍNH (MAIN IDEA)

**Mindset chung khi tìm ý chính:**
Loại bỏ các thành phần bổ nghĩa (mệnh đề quan hệ, cụm giới từ rườm rà), tập trung vào cấu trúc lõi `[S] + [V]` và các liên từ nối `because / yet / for / after...`. Nếu câu có cấu trúc đặc biệt (câu chẻ, câu tường thuật), cần nắm bắt thông tin nằm ở vị trí nhấn mạnh.

**Luyện tập rút ý chính:**

1.  *Câu gốc:* Research into people's happiness, which was carried out by a group of scientists, found that money is not the most important factor.
    *   $\rightarrow$ **Phân tích:** Lược bỏ mệnh đề quan hệ bổ nghĩa "which was carried out...", chú ý động từ tường thuật "found that". 
    *   $\rightarrow$ **Main idea:** Money is not the most important factor.

2.  *Câu gốc:* In some remote areas, where local farmers still adopt conventional farming practices, modern technologies brought about by agricultural specialists across the country can make a big change to the farmers' lives.
    *   $\rightarrow$ **Phân tích:** Lược bỏ "where local farmers..." (mệnh đề phụ bổ sung) và phần rút gọn "brought about...". 
    *   $\rightarrow$ **Main idea:** Modern technologies can make a big change to the farmers' lives.

3.  *Câu gốc:* Lisa, who went to Vietnam last year on a summer trip with her long-time boyfriend Justin, has said that even though the country may not be the most economically developed in the region, it has some of the most spectacular views that a person traveling to countries in Asia can ever see.
    *   → **Phân tích:** Lược bỏ "who went to Vietnam..." → tìm thấy "has said that" (Reported speech). Sau "that" là cấu trúc Tương phản (even though SV, SV). 
    *   → **Main idea:** VN mặc dù chưa quá phát triển kinh tế nhưng có phong cảnh đẹp.

4.  *Câu gốc:* Although people who feel happy will smile a lot, research has shown that sometimes it is the act of smiling that makes people happy.
    *   → **Phân tích:** Câu có cụm tương phản "Although", có cụm tường thuật "research has shown that", có cấu trúc câu chẻ nhấn mạnh "it is the act of smiling that...". 
    *   → **Main idea:** Cười làm cho con người hạnh phúc.

Dưới đây là nội dung hoàn chỉnh được biên tập lại từ các ghi chép của bạn, giúp hệ thống hóa phương pháp Linearthinking® khi áp dụng vào kỹ năng Reading.

#### 📌 Quy trình 4 bước tiếp cận bài đọc
* **Bước 1: Read the question + understand the meaning**
    * Phân tích cấu trúc Chủ ngữ - Vị ngữ (S-V) của câu hỏi.
    * Đọc kỹ yêu cầu đề bài và thực hiện **Dự đoán (*)**.
* **Bước 2: Locate information**
    * Sử dụng các thông tin đặc biệt (tên riêng, con số, thuật ngữ chuyên ngành) để xác định vị trí đoạn văn chứa câu trả lời.
    * Quét nhanh (S-V quickly) để tìm đúng câu liên quan.
* **Bước 3: Read relevant info → get the meaning**
    * Đọc cấu trúc câu (Read structures) → hiểu chi tiết ý nghĩa (read details).
* **Bước 4: Compare meaning with meaning**
    * Đối chiếu ý nghĩa giữa câu hỏi và nội dung bài đọc (thay vì chỉ đối chiếu từ khóa đơn thuần).

**(*) Kỹ năng dự đoán (Predictions)**

Việc dự đoán giúp bạn chủ động hơn khi đọc bài:

1.  **Dự đoán từ loại (Word forms):** Xác định chỗ trống cần điền là Danh từ (N), Tính từ (adj), Động từ (V) hay Trạng từ (adv).
2.  **Dự đoán loại thông tin (Types of information):**
    * **Danh từ (N):** Có thể là người (human), vật thể (object), nơi chốn (place), sự kiện (event), giai đoạn (period), sản phẩm (product), hay thuật ngữ (term)...
    * **Tính từ (adj):** Mang sắc thái tích cực (positive) hay tiêu cực (negative).

### 1. Tổng quan (General Mindset)
Để kết nối hai câu với nhau (**To connect 2 sentences**), chúng ta có hai phương thức chính:
* **With linking words:** Sử dụng các từ nối tường minh.
* **Without linking words:** Kết nối ngầm định thông qua tham chiếu (**Referencing**) hoặc ý nghĩa (**Meaning**).

---

### 2. Kết nối có từ nối (Connection with linking words)

Khi đọc, việc nhận diện nhóm từ nối giúp ta xác định nhanh phần thông tin nào quan trọng nhất cần ghi nhớ.

| Nhóm từ nối (Linking Words) | Mối quan hệ (Relationships) | Mẹo đọc (Tips) |
| :--- | :--- | :--- |
| **Effect:** Therefore, As a result, Thus, Consequently, Hence (*vì vậy*) | **Hệ quả (A → B):** Vế trước dẫn đến vế sau. | **Nhớ vế 2** (vế B) |
| **Contrast:** However, Yet, On the other hand, Despite this, Even so, By contrast, Still, Surprisingly | **Tương phản (A # B):** Vế sau ngược lại vế trước. | **Nhớ vế 2** (vế B) |
| **Example:** For example, For instance, A case in point is that, To illustrate, Specifically, By way of illustration | **Ví dụ:** Minh họa cho ý đã nói. | **Skip** nếu đã hiểu Main idea (vế A) |
| **Similarity:** Also, Likewise, Similarly, In the same way | **Tương đồng:** Ý tương tự ý trước. | **Skip** nếu đã hiểu Main idea (vế A) |
| **Explain \| Clarify:** In fact, In other words, Indeed | **Giải thích \| Làm rõ:** Giải thích kỹ hơn. | **Skip** nếu đã hiểu Main idea (vế A) |

---

### 3. Kết nối không có từ nối (Connection without linking words)

Sử dụng công cụ **Referencing (Tham chiếu)** để nhận diện sự liên kết giữa các câu khi không có từ nối.

#### 3.1. Tham chiếu trực tiếp (Direct Referencing)
Sử dụng các đại từ thay thế trực tiếp cho danh từ đã xuất hiện trước đó.
* **Dấu hiệu:** *it, they, he, she, them, his, her...*
* **Ví dụ:** **Tribal tourism** is a relatively new type of tourism. **It** involves travellers going to remote destinations. (*"It" ở đây chính là "Tribal tourism"*)

#### 3.2. Tham chiếu gián tiếp (Indirect Referencing)
Sử dụng từ chỉ định kèm danh từ hoặc dùng từ đồng nghĩa để nhắc lại ý trước.
* **Dấu hiệu:** *Such + N, The/This/That/These + N...* hoặc các cụm từ đồng nghĩa.
* **Ví dụ 1:** Her parents **supported her decision**... **Such approval** gave her the confidence... (*"Such approval" thay thế cho cả hành động ủng hộ ở câu trước*)
* **Ví dụ 2:** The **sun** looked so bright... The **fiery ball** filled this part of the day... (*"The fiery ball" là cách gọi khác của "sun"*)
* **Ví dụ 3:** Particular enemies to large trees are **insects**. **These tiny creatures** can kill entire forests. (*"These tiny creatures" thay thế cho "insects"*)

---

### 4. Tóm tắt (Summary)

Sơ đồ tư duy về liên kết câu:
* **To connect 2 sentences:**
    * **With linking words:** (Effect, Contrast, Example, Similarity, Explain)
    * **Without linking words:**
        * **Referencing:** Trực tiếp (*it, they...*) hoặc Gián tiếp (*Such N, The N...*)
        * **Meaning:** Liên kết dựa trên sự logic về nghĩa của hai câu.

### 2. Quy trình thực hiện Linearthinking®

#### Bước 1: Read structures (Đọc cấu trúc)
Giúp hiểu đúng và nhanh ý nghĩa của **một câu**.
* **Imagine the structure:** Hình dung cấu trúc câu trong đầu.
* **Read the main components:** Tập trung đọc các thành phần chính (S-V-O).
* **Read details later (if necessary):** Chỉ đọc các chi tiết phụ khi thực sự cần thiết.

#### Bước 2: Read connections (Đọc liên kết)
Giúp hiểu đúng và nhanh ý nghĩa của **một đoạn văn**.
* **Identify repeated information:** Nhận diện các thông tin được lặp lại (thông qua từ đồng nghĩa, đại từ thay thế).
* **Identify relationships:** Xác định mối quan hệ giữa các câu (nguyên nhân - kết quả, tương phản, ví dụ...).

---

### 3. Ứng dụng vào các dạng câu hỏi Reading

Việc nắm vững hai trụ cột của Linearthinking® sẽ giúp giải quyết các dạng bài IELTS Reading đặc thù:

* **Dựa trên Read structures:** Áp dụng hiệu quả cho dạng bài **TFNG** (True/False/Not Given) và **Gap fill** (Điền vào chỗ trống).
* **Dựa trên Read connections:** Áp dụng hiệu quả cho dạng bài **Matching headings** (Nối tiêu đề).
* **Đối với các đoạn văn khó (Difficult passage):** Luôn dựa trên cấu trúc câu (Sentence structures) và liên kết (Connections) để bóc tách nghĩa thay vì cố gắng dịch từng từ.
