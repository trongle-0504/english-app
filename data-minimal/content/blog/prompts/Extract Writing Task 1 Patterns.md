# 1B. NEW vs. UPGRADE vs. SYNONYM — HOW TO TELL THEM APART

Before extracting anything, apply this test to every candidate pattern:

### ❌ Synonym / trivial restatement (DISCARD)
Same grammatical slot, same sentence shape, only the vocabulary changed.

> Existing: `X increased sharply`
> Source: `X rose sharply` → **discard**, `rose` is already covered as a synonym of `increase`.

### 🔺 Upgrade of an existing pattern (KEEP — mark as Upgrade)
Same function/slot as something in Section 2, but the source version does noticeably more work: it adds a clause, a more advanced structure, a more natural collocation, or combines two things (trend + data, ranking + result, etc.) that my current version handles separately.

> Existing (A3, Difference): `which was [X] higher than the figure for B`
> Source: `a gap that widened from [X] to [Y] over the period` → **keep as Upgrade of A3 > Difference**, because it reframes a static difference as a *changing* one — a genuinely different grammatical function, not just new words for the same job.

> Existing (B4, Increase): `increase`
> Source: `X climbed steadily, reaching a peak of A before tailing off towards the end of the period` → **keep as Upgrade of B4/B7**, because it chains trend + rate + peak + late-stage change into one sentence, which my current single-clause structures don't do.

### ✅ Completely new (KEEP — mark as New)
No equivalent slot exists anywhere in Section 2 at all.

> `X and Y converged before X overtook Y` — no crossing/overtaking structure exists in my current framework → **New**.

When in doubt between Synonym and Upgrade, ask: *if I swapped only the verb/adjective back to my existing vocabulary, would the sentence still do the exact same grammatical job?* If yes → Synonym. If the sentence would lose a clause, a combination, or a nuance → Upgrade.
