# NeuralSymbolic® — IELTS Speaking answer guide

How to build a Speaking answer with the NeuralSymbolic method: a direct answer first, then Linear tools that expand it
one clear step at a time. Patterns are written with placeholders: N = noun, V = verb, V-ing, SV = subject + verb,
Adj = adjective.

---

## 1. The answer flow

```
Question ➔ Direct answer ➔ Linear tool ➔ Linear tool ➔ …
```

- **Sentence 1: the direct answer.** Answer the question at once, using the structure for its question type (section 2).
- **Sentences 2+: Linear tools.** Each sentence adds one tool:

| Linear tool | What it does | Content |
| --- | --- | --- |
| **Description** | Specifies the answer | Verb (what you do, how often/much) · Objects (who/what, what it is like) · Contexts (when, where, with whom) |
| **Cause** | Why: what leads to it | Objective: positive/negative effect, opinion · Subjective: want / need / feeling |
| **Effect** | What happens because of it | Want / need / preference / feeling · Action / habit |
| **Example** | Part 3 and hard Part 1 questions | "Take me as an example." / "Take NOUN as an example." Then answer again with tools |

- Each step is one simple, clear sentence: frame (structure / pattern) + information (vocabulary / collocations).
- **Part 1:** direct answer + 1–3 tools. **Part 3:** specify the question when it is broad (section 4) + direct answer
  + several tools, often with an Example ("Take me as an example").

### Be flexible

The tools are a toolbox, not a template.

- **Let the question and the idea choose the tools.** A "where / when" question often needs Description (context); a
  "why" question needs Cause; "do you like…" suits Cause (feeling / opinion) or Effect (habit); a story from the
  speaker's idea may need Description ➔ Effect ➔ Effect. Use only the tools that carry the idea forward.
- **Any logical order, any mix.** Answer ➔ Description ➔ Effect · Answer ➔ Cause ➔ Effect · Answer ➔ Description ➔
  Cause ➔ Effect · Answer ➔ Effect ➔ Effect · Answer ➔ Cause ➔ Description… A tool can expand the answer or the
  previous sentence, and a tool can repeat when the idea needs it. Do not give every question the same flow.
- **Patterns are starting points.** Use the guide's structures where they fit naturally, and extend them freely: other
  natural spoken frames, other verbs with the same pattern (allow / enable / let sb V), combined or shortened forms.
  Never force a structure that sounds stiff or does not fit the idea.
- **Keep the IELTS length** (section 1.1) whatever the flow.

### 1.1 Length (IELTS standard)

| Part | Speaking time | Model answer |
| --- | --- | --- |
| Part 1 | about 20–30 seconds per question | 3–4 sentences, about 45–75 words |
| Part 2 | 1.5–2 minutes | about 220–320 words (aim for 270) |
| Part 3 | about 40–60 seconds per question | 4–6 sentences, about 60–100 words |

### Cause or Effect?

| | Cause | Effect |
| --- | --- | --- |
| Question it answers | Why do you do it? (motive, the feeling that drives you) | So what happens? (the feeling or wish that comes after) |
| Time / logic | Before the main action: motive ➔ action | After the main action: action ➔ result |
| Connectors | This is because… / The (main) reason is that… | That's why… / As a result,… |

Example: "Do you like listening to music?"
- Answer: I really like it when I get to listen to music.
- Cause (feeling): **This is because** I find it incredibly calming — it helps me forget the stress of the day.
- Cause (want): **This is because** I always want something in the background that keeps my mind off things.
- Effect (feeling): **That's why** I find myself feeling noticeably lighter after every session.
- Effect (want): **That's why** I always want to have my headphones on me wherever I go.

Common mistake: "Do people change a lot?" → *expertise & mindset* answers "change what?" so it is **Description**;
*adapt to their environments* answers "why?" so it is **Cause** — not Cause and Effect.

## 2. Direct answers by question type

### Yes / No

| Degree | Yes | No |
| --- | --- | --- |
| 100% | For sure / Definitely / Totally / Certainly / Without a doubt | Not at all / Definitely not / Certainly not / I don't think so / The answer is a definite no |
| 60–70% | Kind of / Probably / A little bit / I guess so / I would say so | Not really / I wouldn't say so / I guess not / Probably not / I wouldn't go out of my way to say yes |
| 50/50 | I'm not sure / It's really hard to say / Maybe / I'm on the fence about this | |

Pairs: definitely ↔ definitely not · totally ↔ not at all · I guess so ↔ I guess not · probably ↔ probably not ·
I would say so ↔ I wouldn't say so.

> Is learning English useful for students? — **I would say so.** It helps students study and work internationally.

### What / Which / Who

- It would be + N / to V / that SV — "It would be to practise consistently on a daily basis."
- Emphasis ↑: It would be **nothing else / no one else (but / other than / if not)** + N; **none other than** + N
  (no one else → people, nothing else → things / ideas, none other than → a person, place or standout subject).
- Several ↓: It would be **a couple of things / people, one of which / one of whom is** + N / to V.
- Who: That person must / would be… / The person that + V is…
- What kind of: It must / would be… / The thing that + V is…

### Where / When

- Present: I (often) V / do it + **[place / time]** + when SV / where SV.
- Present: **[place / time] + when SV / where SV** + is (usually) a good place / time for me to V.
- Past: If I remember correctly, it was + [place / time].

| Time: morning / start of the day | Time: evening / end of the day |
| --- | --- |
| first thing in the morning | last thing before bed |
| at the crack of dawn | at dusk |
| when I'm the first one up | when I'm the last one to turn in |
| when I'm buried under work | whenever I have some time to spare |

| Place: outside / alone | Place: inside / crowded |
| --- | --- |
| outside of the house / out and about | in the comfort of my house / room |
| where it is quiet | where it is lively and noisy |
| where it is just me and myself | where there are people in the background |
| where it is tranquil and calm | where it is lively and full of energy |

> When do you usually work on your projects? — I often work on them **last thing before bed, when there are fewer
> distractions around me**.

### How

| Type | Structures |
| --- | --- |
| Method (How?) | S + can V / do this **by V-ing** · S + can V **to** V · **A good idea would be to** V |
| Quantity (How much / many / far / long?) | (around / about / somewhere in the ballpark of) + quantity · quantity **give or take** · **A lot more / less than I care to admit, to be honest** |
| Frequency (How often?) | S + V + frequency expression · S + adverb of frequency + V, about [number] times a day / week |
| Degree (How Adj?) | It is **as Adj as it can be / as it gets** · It is really Adj · It is **not exactly very** Adj (softened) · It is **not at all** Adj (strong no) |

Adverbs of frequency: always 100% · usually 80% · often 60% · sometimes 40% · occasionally 25% · rarely 10% · never 0%.

Frequency expressions (most → least): all the time · every single day · nearly all the time · day in and day out ·
on a regular basis · almost every day · very frequently · first thing in the morning · quite often · last thing
before bed · whenever I have some time to spare · from time to time · every now and then · once in a while.

### Why

| Type | Structures |
| --- | --- |
| Fact | **The (main / simple) reason for N is that** SV · **A big part of the reason goes to** N / the fact that SV · **(Part of) the reason (for N) is that** SV · **For the simple reason that** SV · **The reason** SV **is that** SV |
| Advantage / disadvantage | **The best / worst part about N is that** SV · **What I like / hate most about N is that** SV · **The thing that I like / hate most about N is that** SV |

> Why do you like working alone sometimes? — **The best part about working alone is that** I can focus more deeply on
> my tasks.

## 3. Patterns for the Linear tools

### Positive effects (Cause: objective +)

- Subject = thing / activity (it, V-ing, N): **allow sb to V** · **help sb V** · **encourage sb to V** ·
  **give sb the opportunity / chance to V** · **reduce the risk of N / V-ing** · **increase the chance of N / V-ing** ·
  **give sb N** · **provide sb with N** · **equip sb with N**
- Subject = person: **have the opportunity / ability to V** · **be able to V**

> Studying abroad **gives students the opportunity to experience** different cultures.

### Negative effects (Cause: objective −)

- Subject = thing / activity: **make sb V** · **give sb no choice but to V** · **require sb to V** ·
  **cost (a lot of) money to V** · **take (a lot of) time / effort to V** · **prevent / stop sb from V-ing** ·
  **discourage sb from V-ing** · **distract sb from N / V-ing** · **increase the risk of N / V-ing**
- Subject = person: **have to V** · **have no choice but to V** · **can't help but have to V**

> Watching screens for too long can **distract children from studying**.

### Want / Need (Cause or Effect: subjective)

**want to V / N** · **need to V / N** · **wish to V** · **I wish to be able to V** · **hope to V / hope that SV** ·
**I am all about being able to V these days** · **I truly long to V**

> I **wish to be able to express** my ideas more confidently.

### Feeling / Opinion (Cause or Effect)

| Opener | Subject | Pattern | Use |
| --- | --- | --- | --- |
| I believe that / Personally, / To me personally, / From my point of view, / From my perspective, | person | S + V | basic opinion |
| | person | **find it + Adj to V** | judging an action |
| | person | **consider N to be Adj** · **consider / see N1 (as) N2** | judging a thing or person |
| | thing / activity | **It is Adj to V** | general comment |
| | thing / activity | **make sb feel + feeling Adj** | emotional effect |
| (no opener) | person | **think S should V** · **can't help but feel + feeling Adj** | strong opinion or feeling |

- Quality adjectives (with find it / consider / It is): beneficial, useful, convenient, exciting, fascinating,
  relaxing, easy · harmful, useless, pointless, inconvenient, dangerous, difficult · boring, tiring, exhausting.
- Feeling adjectives (with feel): fascinated, relaxed, confident, happy · unsafe, confused, upset · bored, tired,
  exhausted.

> Many people **find it relaxing to spend** time with pets because pets help them feel less lonely.

### Preferences

- Subject = thing / activity: **is (not) my cup of tea** · **is (not) my interest**
- Like: **really like / enjoy V-ing** · **take a (great) interest in N** · **be (so) into N** ·
  **be particularly interested in N** · **be a (big) fan of N** · **like it when I get to V**
- Dislike / neutral: **don't have a strong opinion about N** · **not too crazy about N** · **hate it when I have to V** ·
  **can't stand V-ing**
- Choice: **'d rather V than V** · **prefer N to N**

### Comparison & Habit

- Comparison: **is a whole lot more / less Adj than…** · **totally beats… (in terms of N)** ·
  **totally pales in comparison with… (in terms of N / how Adj)**
- Habit: **('ve) made / make it a habit to V** · **make a habit out of V-ing** · **'ve habitualized V-ing**

### Description frames

- Specify nouns: **The N that… would be…** · **The N that… would be nothing else / no one else (but / other than /
  if not)…** · **There're a couple of Ns that…, one of which / out of which at the top is N**
- Specify verbs: habit patterns (above) · preference patterns: **like it when I get to V** · **'d rather V than V** ·
  **hate it when I have to V**

> What do you do in your free time? — **It would be to** listen to music. (Description, verb) I always find a quiet
> corner, get my headphones and put on a nice song. (Description, object) **The music that I like most would be**
> slow-paced instrumental songs. (Description, context) I do this pretty much every night **whenever I get to have
> some me-time**.

## 4. Part 3: Specify the question

1. Find the general / abstract information in the question (a noun: things, people, actions, places, times).
2. Specify it into concrete cases.
3. Answer each specified case with a direct answer + Linear tools.

Example — specifying ADVERTISING: type of product (medicine, food, toys, clothes, services…) · form (pop-ups, TV
ads, billboards…) · aspect (visuals, music, message, storyline) · audience (men, women, children, teenagers) · who is
involved (companies, customers, the economy) · frequency (rarely ➔ always).

Markers:
- Introduce the split (Marker 1): **It (totally) depends on** N / the group / kind of N / how-what-where-when SV
  **(we're talking about / really)**.
- Lead into each case (Marker 2): **When it comes to N…** · **If you look at N…** · **Now, if we're talking about N…** ·
  **I'd like to think / talk about N…** · **It kinda causes me to think about N…** · **First thing in my mind now is N…**
- Personal example: **Take me as an example.**

> Do people change a lot? — Yes, absolutely. I believe that people change significantly over time. (Description)
> Specifically, their expertise and mindset tend to evolve as they grow older. (Cause) This is because they need to
> constantly adapt to their changing environments. **Take me as an example.** I have definitely changed a lot since I
> was a child: I have become much stronger emotionally. (Effect) As a result, I no longer cry easily over minor
> problems, (Effect, opinion) and I think this is a very good change for my personal development.

## 5. Part 2: the Linear framework

| Cue card part | Framework | Content | Marker |
| --- | --- | --- | --- |
| Topic | **Lead-in** | name the subject | There are many Ns that I can think of, but the one that comes to mind first is N. |
| 3 short cues | **Introduction** | basic information: each cue = an idea + 1 Linear tool | To tell you a little bit about N, SV. |
| "and explain why…" | **Body** | answer + several Linear tools | Now, the reason why [topic] is that SV. / Now, to tell you […], SV. |
| — | **Conclusion** | one closing sentence | Anyway, all in all, SV. That's all I have to say. Thank you. |

Note-taking: no notes for the lead-in or conclusion; for each cue, an idea + its tools; for the body, the answer + its
tools. Example (something you own): lead-in *a jacket I got on my birthday* · intro *from a friend, birthday present ·
had it for 2 years, wear it every single day · drive around a lot* · body *reminds me of my friend ➔ a caring person ➔
helped me a lot, offered advice at my lowest ➔ treasure it, keep it clean and new*.

### Personalize the idea

1. Choose a subject close to yourself.
2. Link it to an aspect: **Impact** (how it changed your actions or views) · **Traits** (your personality ➔ what
   happened) · **Feeling** (what emotion it creates) · **Want / need** (what wish it creates).

Personal lead-ins:
- Traits / wants / needs: **I'm personally someone who…, and that's why I immediately think about N.**
- Feelings: **I can't help but feel… whenever I think about N.**
- Impacts: **Of all the Ns, one that… me the most is perhaps N.**

> (Lead-in) There are many places that I can think of, but the one that comes to mind first is a coffee shop called
> Little Prince. (Introduction) To tell you a little bit about this coffee shop, it is a small one located in an alley
> in District 7. As a result, it is as hard to find as it gets. A friend of mine introduced me to it… (Body) Now, the
> reason why I like to study and work here is that it offers a very peaceful atmosphere… (Conclusion) Anyway, all in
> all, it's just a wonderful place to work. That's all I have to say. Thank you.

## 6. Simplify & think in English

When you do not know the English word, simplify the idea and say it with basic English.

- **Verb you don't know** ➔ a simpler verb + object (what?) / manner (how? adv, in a way that SV, with / without N) /
  context (where / when? prep + N, where / when SV) / purpose (what for? (just) to V, (just) so that SV).
  *tảo mộ* ➔ visit and clean up (the graves) to pay our respects · *rước đèn* ➔ go around the neighbourhood together
  with a special type of lantern.
- **Noun you don't know** ➔ a general noun (this N, one of these Ns, a kinda N, a very special N) + description
  (character: that is / seems really Adj · action: that V · relationship · length: that I have V3 for / since… ·
  importance) or example (the likes of N, such as N).
  *tiền lì xì* ➔ money that is put in a red envelope for good luck · *lễ vật* ➔ traditional gifts, such as fruit, tea
  and sticky rice.

## 7. Worked examples (Part 1)

**What is your favourite holiday?** — Flow: Answer (Tết) ➔ Description (date not fixed, Jan–Feb) ➔ Cause (lunar
calendar) ➔ Effect (confusing for other cultures) ➔ Cause (interesting) ➔ Effect (look forward to it every year).

> Without a doubt, my favourite holiday is Tet. Unlike standard calendars, the date of Tet is not fixed and varies
> between January and February. This is because it is based on the lunar calendar, which is why it can be slightly
> confusing for people from other cultures. However, I find this unique aspect very interesting, and that's why I
> always look forward to it every year.

**Do you think holidays are important?** — Flow: Answer (yes) ➔ Cause (clear my mind and recharge) ➔ Effect (look
forward to the next Tết).

> Yes, holidays are extremely important. The main reason is that they allow me to completely clear my mind and
> recharge my creative energy. That's why I am already looking forward to the next Tet holiday to unplug entirely.

**Where did you go on your last holiday?** — Flow: Answer (hometown) ➔ Cause (see my parents) ➔ Description (had not
seen them for half a year) ➔ Effect (missed them) ➔ Effect (overjoyed when we met).

> On my last holiday, I travelled back to my hometown to see my parents. Because of my heavy workload, I hadn't seen
> them for more than half a year. As a result, I missed them terribly, which is why we were all extremely overjoyed
> when we finally met.

**Do you like taking the bus to school?** — Flow: Answer ➔ Description ➔ Cause ➔ Effect.

> I really like it when I get to take the bus. The bus route that I take most often would be the one from home to
> school and back. This is because mom and dad are too busy to give me a ride in the morning. That's why they asked me
> to go by bus.
